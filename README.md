# Automarket

Агрегатор объявлений по Узбекистану — старт с авто (OLX, Avtoelon,
Telegram-каналы), считает `deal_score` (насколько цена ниже/выше рынка для
сегмента) и показывает лучшие предложения. Карточка = наши данные + ссылка
на оригинал, чужой контент не хостим.

## Структура

- `openapi.yaml` — контракт API (источник правды по всем полям)
- `fixtures/` — примеры ответов API для разработки фронтенда без бэкенда
- `frontend-brief.md` — ТЗ по экранам для верстки
- `parsers/`, `db/`, `api/` — бэкенд (в разработке)
- `web/` — фронтенд (планируется отдельно, см. frontend-brief.md)

## Для фронтенда (ChatGPT или кто угодно)

Верстать по `openapi.yaml` + `fixtures/*.json`, ТЗ по экранам —
`frontend-brief.md`. Бэкенда пока нет, запросы идут на локальные файлы,
позже просто подменяются на реальный API по тому же контракту.
