# Automarket — бриф для фронтенда

Агрегатор объявлений по Узбекистану (старт с авто): собираем объявления с
нескольких площадок, считаем `deal_score` — насколько цена ниже/выше рынка
для этого сегмента — и показываем самые выгодные предложения. Мы не хостим
чужой контент: карточка = наши данные + ссылка на оригинальное объявление.

Контракт API — `openapi.yaml` в этом же пакете. Реального бэкенда пока нет —
верстать на файлах из `fixtures/` (`listings_page.json`, `listing_detail.json`),
запросы к `/v1/listings` и `/v1/listings/{id}` потом просто подменяются на
реальный fetch к тому же контракту.

## Экраны

### 1. Лента (главная)
Список карточек, отсортирован по `deal_score` по убыванию (лучшие сделки
сверху). Фильтры сверху: категория (пока только "Авто"), марка/модель, город,
диапазон цены, диапазон года. Сортировка: по deal_score / по цене / по дате.

Карточка в ленте:
- фото (`photo_url`)
- заголовок (`title`), город, "N часов назад" из `posted_at`
- цена (`price_usd`, мелким — `price_uzs`)
- визуальный индикатор deal_score: например прогресс-бар/бейдж с текстом
  ("Отличная цена" при >0.2, "Хорошая цена" 0.1–0.2, "По рынку" −0.05–0.1,
  "Дороже рынка" при < −0.05 — но конкретные пороги и подписи можно
  предложить свои, главное чтобы это было видно с одного взгляда)
- 1–2 самых важных `flags` (если есть) — коротким тегом
- источник (`source`: olx/avtoelon/telegram) — небольшой значок/лейбл

### 2. Карточка объявления (детальная)
Всё из ленты + :
- галерея `photos`
- таблица атрибутов `attrs` (для авто: марка, модель, год, пробег, коробка,
  позиция, растаможен)
- **сравнение с сегментом**: "Медиана по 47 похожим авто: $11 000" —
  это должно быть заметно, это и есть объяснение deal_score
- список всех `flags` — см. ниже про разделение по `source` flag'а
- график/спарклайн истории цены (`price_history`), если есть больше 1 точки
- **description_raw** — исходный текст объявления как есть, без причёсывания
- крупная кнопка **"Открыть объявление →"** на `source_url` (открывается в
  новой вкладке) — это главный CTA, весь контакт с продавцом происходит
  там, не у нас

### 3. Важно про `flags`
У каждого флага есть `source`:
- `text` — продавец сам написал это в объявлении → показывать как факт
- `photo_heuristic` — предположение модели по фото/поведению → обязательно
  визуально помечать как предположение (например иконка "?", менее яркий
  цвет), не смешивать с `text`-флагами
- `price_history` — посчитано из истории цен → нейтральный инфо-тег

Это важно: если смешать типы визуально, сервис теряет доверие при первой
же ошибке эвристики.

## Стиль
Свободно на ваше усмотрение, только:
- должно нормально работать на мобильном (основная аудитория — с телефона,
  вероятно из Telegram-бота по ссылке)
- тёмная и светлая тема — как решите, но не завязывайтесь только на system
  предпочтение, если можно дать переключатель
- никаких изображений/фото с реальных чужих сайтов — только заглушки/моки
  из fixtures, реальные фото будут отдаваться по прямым URL с сервера, CDN
  площадок — это не наш хостинг

## Что НЕ входит в фронтенд сейчас
- Личный кабинет / регистрация — алерты настраиваются через Telegram-бота,
  не через сайт
- Оплата/подписки — не в этой итерации
- Расчёт deal_score, флагов, медианы — всё уже приходит готовым с бэкенда,
  фронт это не считает, только отображает
